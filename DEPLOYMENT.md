## 🚀 Quick Vercel Deployment Guide

This project is fully prepared for instant 1-click deployment to **Vercel** with complete SPA routing (`vercel.json` already configured).

### Method 1: Via GitHub (Recommended - Takes 1 Minute)
1. In Google AI Studio, click the **Settings / Menu** in the top navigation bar and select **Export to GitHub**.
2. Go to [vercel.com](https://vercel.com) and log in with your GitHub account.
3. Click **"Add New..."** > **"Project"**.
4. Select the exported repository and set the Project Name as:
   `abhaybhuj-assignment-golfncharity`
5. Click **Deploy**.
6. Your live Vercel link will be:
   `https://abhaybhuj-assignment-golfncharity.vercel.app`

### Method 2: Via Vercel CLI
If you download the ZIP:
```bash
npm install -g vercel
vercel
```
Follow the simple terminal prompts to deploy.
